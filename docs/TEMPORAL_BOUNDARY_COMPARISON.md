# Paired temporal boundary diagnostics

This is an opt-in measurement comparison, not a new crop policy. Start a diagnostic build with `VP_LOCAL_BOUNDARY_TRACE=shadow-refined` to compare the existing coarse and source-refined local-boundary sessions on identical captured frames. `shadow` preserves the original coarse-only trace; absent/unknown values run neither. No other experimental flags are enabled by this option.

Both sessions receive one shared 128 x 270 source grid and the same source identity/time/context. Refinement reuses the existing bounded source-pixel helper, with at most 8,192 extra reads per observation. Fine pixels count as their original spatial bin, not extra spatial coverage. Sessions have independent histories/anchors and are reset together for observed scene cuts, invalid source, transport gaps and diagnostic exceptions. Generation and continuity changes remain handled by the existing session. Paused repetitions cannot create spatial diversity.

Observations retain the existing 200ms cadence and 600-observation lifetime budget (roughly two minutes), with no background worker, frame copy or downscaling. Diagnostic CPU work remains on the render thread; pair_inspection_ms must be measured on the real input before assuming its cost. It covers sampling/analysis only, excluding subsequent log formatting and writes. It runs only on valid existing CPU analysis views. This is bounded sampling, not inspection of every exterior pixel.

`Alpha local-boundary comparison` records pair the coarse/refined paths by instance/sample/source generation/sequence. They include proposed boundaries, extra read counts, refinement/rejection reasons, supported-column masks, union/new coverage, distinct masks, history resets, and retained-anchor exterior results. `ambiguous=1 policy_effect=none` always applies: a qualifying diagnostic hypothesis is not safe crop admission. Production eligibility is intentionally not duplicated here; correlate the same instance/sequence with native detection, near-black, presentation/admission and sparse-experiment records where available. In particular this mode must not enable startup/transition experiments or bypass caption, near-black or side-evidence checks.

For a replay, begin before the difficult moving yellow patch, dismiss the HDMI playback menu, play 30–60 seconds, then pause. Compare genuine new horizontal support along stationary boundaries against pauses, moving internal artwork, a desk-like dark region, captions/OSD, gradual aspect changes and source discontinuities. Window size/UI is not source evidence. A moving object on a black full-frame background can resemble letterboxed content; temporal agreement alone does not establish intent.

The normal packaged binaries and setup/ZIP remain unchanged until a separate requested deployment. Keep the evidence and prototype even if it does not improve Alien acquisition; do not tune thresholds to force the example to pass.
