# Archived: VP-0028 renderer configuration proposal

This document described the superseded VP-0028 configuration grammar:
`[profile_groups.*]`, `[profiles.*]`, renderer-specific configuration aliases,
disk-persisted profile selections, and the legacy shader rule registry.

The replacement review specification is
[VP-0079 Configuration Model Proposal](VP-0079_CONFIGURATION_MODEL_PROPOSAL.md).
It defines the proposed single-file, namespace-based configuration model and
clearly separates target syntax from syntax accepted by the current binary.

For a browser-friendly version, open
[VP-0079_CONFIGURATION_MODEL_PROPOSAL.html](VP-0079_CONFIGURATION_MODEL_PROPOSAL.html).
