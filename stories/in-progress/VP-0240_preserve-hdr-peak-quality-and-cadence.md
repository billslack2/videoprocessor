## Live video priority and lookahead clarification — November 26

The user prioritizes continuous current-source video and smooth presentation over an occasional transient subtitle blend, missing cue, or other one-frame subtitle imperfection. A stutter, dropped source or growing backlog is unacceptable. Evaluate cue reuse and output selection against that priority. Do not increase buffering, lookahead depth, delays or timeouts to conceal an overrun.

The existing progressive Smooth Motion path buffers two source frames in the observed 23.976 fps configuration. That delay may create scheduling slack for work that can overlap, but it does not enlarge the display interval or the sustained 41.7 ms source interval. A single optional analysis can exceed a source interval if it uses existing slack and current video remains on schedule. A worker that must analyze every incoming frame cannot sustainably average above the source interval. A late, stale or unavailable optional result must not hold the whole movie frame or block current-source presentation. Do not invent cue absence or reuse old movie/cleanup pixels as current-source evidence.

The .11 subtitle worker has one active job, up to eight queued jobs and up to sixteen ready observations. It prioritizes nearby frames, rejects or replaces pending work at capacity, and expires queued work behind the advancing source head. Active work is not preempted. Submission and result lookup take mutexes, so the asynchronous design is not a guarantee of zero contention. The separate active-picture lookahead runs on the renderer pre-render path under a phase-based budget capped at 2 ms, with backlog/repeats suppressing admission. The source queue has a hard capacity and can drop frames under pressure. Inspect actual source progression, presentation gaps, queue age and drops, optional work retirement, and worst total critical path in matched playback. Do not infer that queue bounds prove deadline compliance.

The current temporal path contains warmup, missing-snapshot and packet-readiness conditions that can skip a submission, and an existing subtitle fallback can select an older complete movie picture for up to two source intervals. Investigate and eliminate any dependence on these paths for optional cue readiness in a focused trial before claiming the live-video contract is met. Preserve genuine timing and device transitions and use a current-source pixel-preserving fallback for unresolved optional work.
