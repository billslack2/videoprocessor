Current contract
----------------
1. Keep source-picture geometry and subtitle-safe presentation geometry distinct. `AspectLimitFillInput::sourceBounds` is presented bounds; optional `contentReferenceBounds` can veto fill but cannot change crop bounds (src/VideoProcessor-Lib/vprenderer/AlphaSourceCropPolicy.h:924-942). `Decision::sourceBounds` is the selected picture rectangle (:1420 onward). `BuildCaptionBoundedFitAcquisition` says caption supplies extent, never picture authority (:1588 onward); it requires native trusted picture plus same-frame caption and current visible witness, each bound to source generation/sequence, then ensures the envelope contains picture, caption and visible pixels (AlphaSourceCropPolicy.cpp:4770-4850). A boundary-derived physical aperture should supply aspect/crop contract; caption bounds remain a separate envelope/veto/translation input. Do not derive target aspect from an envelope enlarged to include caption ink.

2. The active caption gate is exact-frame, not a free-standing historical rectangle. Renderer passes `currentConfirmedCaptionBounds` and current generation/sequence to caption-bounded acquisition and cold-caption presentation (LibplaceboVideoRenderer.cpp:16690-16700, 16924-16953). The latter also passes strict native picture proof, current observation, retention result/base and source identity. Its builder requires exact generation/sequence/epoch plus independently current native bounds and caption evidence, includes current visible pixels before returning OUTWARD_FIT (AlphaSourceCropPolicy.cpp:4872-5155).

3. Do not make subtitle glyph masking or a raised matte the physical-bar baseline. Black-reference code has a separate matte reference; `CentralCaptionDoesNotDestroyRaisedMatteReference` checks raised levels 40 and 64 remain FULL_UNRESOLVED_RAISED with original floor and one qualified edge (ActivePictureBlackReferenceTests.cpp:158-175). This permits a central caption without moving the sampled reference, and does not make the unqualified opposite edge trusted. New boundary samples should keep robust unaffected-edge/reference samples separate from localized caption pixels; where subtitle intersects edge, retain a per-edge guard/veto and use current caption ownership only for display preservation.

4. Queued proof binds to `ActivePictureFrameIdentity`, native source generation/format and live viewport generation; shader generation is a distinct guard (BufferedPictureExpansion.h:27 onward). Consumers revalidate current identity and pixels, and subtitle vetoes / exact physical subtitle base are covered in LookaheadOutwardProofTests.cpp: `BufferedConsumerPreservesCurrentEvidenceContextAndSubtitleVetoes`, `CurrentContextRejectsStaleBasePolicyContinuityAndOwner`, `TranslatedOwnerRequiresSameSourceAndPhysicalSubtitleBase`, `ReadyCertificateNeverBypassesCurrentPixelsOrCaptionOwner`. Do not let queued samples become independent authority, skip current-frame admission, or reset another presentation owner. Keep same-generation common owner episode through candidate/boundary confirmation; retire old subtitle translation only after accepted crop adoption/submission under existing consumer path.

Staged minimal implementation proposal
--------------------------------------
Stage A (no presentation changes): add an independent boundary-led native sample for horizontal luma/chroma edges to nominate candidate source-picture top/bottom across quartiles. It inspects current native pixels and returns nominal measured edge positions, per-edge quality/reference evidence, and a separately labeled conservative retained fringe. Nominal edges are the only candidate source-aspect measurement; conservative fringe is only an uncertainty/display-containment margin, never the true aspect. Keep subtitle/caption-safe envelope separate again. This returns neither cropped AR nor authority. Preserve current raw/strict-black detector; do not overwrite black baseline or make bright upper exterior count as black. Run on supported formats and feed nomination only to normal identity/route transition state, not generic native authority.

Stage B: nomination alone cannot advance a route to publishable authority. Before temporal confirmation can publish, require separate complete exterior qualification for the entire excluded outside bands and reconcile current visible/source pixels against the nominal aperture and conservative fringe. More votes do not make unsafe outside-band pixels safe. Use the normal consecutive-source route only after that independent qualification; do not pool an endpoint from this cue with another route. Keep existing scene/cadence handling, source identity, generation, base-crop contract, transition/owner state, and final admission. The exact current frame must still revalidate both boundaries and visible extent immediately before crop publication.

Stage C: present the accepted source aperture through existing crop/aspect policy. Continue separate confirmed subtitle bounds, current visible extent, subtitle translation/replacement and composed glyph checks. If text overlaps the crop, preserve it by existing subtitle mode/translation or a current caption-safe envelope; never enlarge aspect measurement itself to fit the caption. The route should not make subtitle-fit settings an AR detector input.

Acceptance cases
----------------
- Captured YTTV sample: detect repeatable straight y≈301/302 top and y≈1856 bottom despite raised/variable upper exterior; yield measured source aperture independent of configured screen aspect, fixed aspect, and fit.
- Captions at center and intersecting each boundary: same physical edge result as no-caption sample; glyph remains visible through existing handling; caption pixel cannot establish/redefine bar reference or crop aspect.
- Four formats (including P010, P210/YUV422 and V210 where current test harness supports them), odd/chroma-misaligned edge, varying raised exterior, boundary gaps/curves/non-full-width panels, and bright scenery controls.
- No boundary from subtitle rectangle, opaque card, UI/menu strip, scene transition or single endpoint; no mixed route history; stale generation, sequence, source format, viewport, shader or base crop rejected.
- Current frame grows visible picture outside nominee, caption moves outside its prepared/captured envelope, old fit/translation owner is present, or final presentation admission blocks: retain current safe presentation or defer, with no lost glyphs and no stale crop publication.
