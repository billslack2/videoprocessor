# Adaptive aspect-ratio evidence: review and proposed design

Review date: 2026-10-26 (America/New_York). Source: `billslack2/videoprocessor`, current GitHub beta/default branch `v1.4.02-beta`, fetched at `7394ba420999a8fa708718ee4ce4d87e7459369f`. Review worktree: `E:\codex\videoprocessor\ar-dynamic-evidence-review-20261026`.

This is a design review, not an implemented fix or a claim of regression-free playback. Three independent reviewers covered transition timing, bar/dark-picture evidence, and regression safety. The user reports slow scope-to-IMAX/16:9 changes and frequent bright YouTube TV ads with obvious borders that never acquire. The native capture subsequently confirmed a bright ad with an uneven, raised upper exterior band and a near-black lower band. This is a different failure from the uniform Full-range synthetic fixtures; the real capture uses Limited range.

## Recommended direction

Use strong current evidence more consistently, with separate proofs for each kind of scene. First extend the existing dark-picture proof into lookahead and remove priority-induced proof restarts. In parallel, qualify separate uniform-matte and spatially varying exterior routes. The recorded ad requires the latter; the initial uniform, matching-matte proposal is insufficient. Treat dark-episode ownership and dark full-raster endpoints as separate changes with additional tests. Preserve existing confirmation counts until evidence shows a remaining timing problem.

The objective is correct, stable framing: promptly follow real aspect changes, preserve actual picture and captions, stay steady through ambiguous scenes, and avoid added queue delay. A strong border is a useful observation; it is not by itself permission to discard everything outside it.

## Configured presentation goal

The 2026-10-27 user clarification confirms a 2.35:1 scope screen with constant image height. Read the active deployment configuration and selected state before interpreting AR diagnostics. Detect the actual picture inside the input container, then apply the configured CIH mapping and aspect-fill limits. Full-raster retention is a conservative detector outcome, not a successful presentation criterion: a scope picture letterboxed inside a 16:9 input can remain undersized with borders on all four sides when the whole raster is fitted to screen height. Tests must measure the final displayed active picture, including expected screen-width scope presentation and screen-height 16:9 presentation, with the current 2.32/2.42 fill limits respected.

The [capture interpretation](native-capture-20261026.md#cih-interpretation-corrected-on-2026-10-27) records the configuration evidence. Boundary straightness and distributed local contrast remain useful evidence despite the failure of one coarse smooth-profile experiment. That failed experiment does not establish that the visible boundary itself is ambiguous. Continue qualifying each edge and protecting actual picture/caption detail; do not require the user to redefine the purpose of automatic AR detection.

## What is already implemented

The detector already adapts its black reference every frame, qualifies some raised mattes, compares local boundaries, checks distributed dark-picture texture, learns recurring geometry, and uses already-buffered future frames. There is no temporal learned black-level calibration in the inspected paths; recurring geometry still requires current pixel proof.

Once all gates pass, ordinary live outward confirmation takes three source samples, followed by the second transition-model vote on the fourth changed frame. A change beginning at sequence 100 is published at 103: approximately 125 ms at 24 fps, not a multi-second timer. Existing broad-picture lookahead can present the new geometry on the first changed frame with two suitable future frames already queued. Long failures therefore need measurement, proof-reset, ownership, and final-submission diagnosis before changing timers.

### Complete queued-route integration

The native-distributed change must update typed certificate production, current-frame consumer validation and progressive-onset suppression together. `BufferedPictureExpansion.cpp:899,923` currently rechecks broad evidence in the latter paths; changing the producer alone will either be ineffective or leave inconsistent safety checks. A progressive dark-window regression must prove that the new queued certificate cannot publish an intermediate rectangle before the motion tracker recognizes expansion.

Preserve the existing broad-only scope of queued subtitle-TRANSLATE retirement (`BufferedPictureExpansion.cpp:943-950`) initially. A distributed certificate may accelerate a transition only where current owner policy already allows it; extending retirement to that route is separately qualified work.

Independent broad/distributed runs keep their own anchors, predicate results and votes, but share the same bounded presentation episode and original owner provenance. Selecting a completed route must not reset the common first-picture sequence, clear prior vertical-presentation ownership, restart the suppression budget, or fabricate an owner-free episode. Existing handoff checks use `firstPictureSourceSequence` and `verticalPresentationSeen` (`AlphaSourceCropPolicy.cpp:950-960,1039-1042`). Include alternating routes with existing TRANSLATE, FIT and drift owners; require unchanged owner eligibility and bounded handoff lifetime.
### Why bright raised bars can fail

All numbers below are in the detector's ten-bit analysis-luma domain, not screen brightness or raw eight-bit UI RGB.

`ActivePictureEvidence.cpp:1062-1084` estimates perimeter P10, forces floor 0 below observed code 32, otherwise caps floor at 80, and caps cutoff at 104. Therefore uniform bars at 25-31 can miss rough nomination with cutoff 24; bars above 104 also cannot pass the ordinary black-line nomination. Full-range matte qualification at line 168 additionally rejects measured Y above 80. A uniform 81-104 band can be nominated but rejected, after which nominal full-extent support above 48 can produce full-raster authority (`:1319-1332`). Limited and Unknown range follow different paths; they must be evaluated separately.

A 39-case unchanged-beta P210 characterization confirmed these discontinuities; 15 cases missed the authored bars. See [executed evidence](evidence.md). The captured ad is Limited range with a nonuniform upper band, so this synthetic Full-range mechanism must not be presented as its cause. The existing positive matte matrix primarily covers 0, 40 and 64 (`ActivePictureBlackReferenceTests.cpp:131-155`).

A nomination-only change is insufficient: retention separately caps P90 at 104 (`ActivePictureEvidence.cpp:589-601`), while strip resampling caps the floor/cutoff again (`:2618`). A local matte certificate must remain meaningful through current-frame retention and final admission, or detection may immediately lose authority and oscillate.

### Uniform relative-matte certificate

This first route remains deliberately limited to uniform, matching mattes. It does not solve the newly captured ad. Keep its qualification distinct from the variable-profile route below.

Start with clear, stationary, opposing, neutral mattes around a full-width bright picture, on one cropped axis. Preserve current symmetry, orthogonal-axis and windowbox rules. Do not initially expand the scope to arbitrary tinted frames, slides, decorative borders or four-sided graphics.

1. **Nominate without calling the band black.** From bounded edge profiles, find a flat exterior region and a common abrupt transition. Record exact candidate, independent per-edge Y/U/V references, noise, uncertainty, support, scan completeness and sampling phase. Proposal generation does not modify the current trusted rectangle.
2. **Verify the whole proposed exterior.** Inspect multiple depths from raster edge to boundary and separated flanks/center segments. Opposing references must agree. Start with current conservative dispersion/agreement limits rather than relaxing level, noise and chroma together. Budget exhaustion is unavailable evidence, never safe matte.
3. **Verify local boundary contrast.** Compare paired inside/outside samples at the same columns, across every spatial quartile on both edges, then require picture continuation through multiple interior depths. A candidate seed is `delta >= max(absolute_minimum, k * exterior_noise)` with a quantization floor; `k` is uncalibrated, and is not a shipping constant. Preserve the current ordinary/thin-bar contrast minima initially (10/18 analysis codes). High noise makes qualification harder.
4. **Preserve contradiction checks independently.** A robust median must not hide a thin object, caption, logo, connected picture, colored detail or disagreement between candidate and final boundary. Inspect the final excluded region and its adjacent rows. Recognized captions remain a separate presentation/cleanup responsibility; relative matte authority never authorizes text erasure.
5. **Issue an exact, typed certificate.** Bind source identity, native/converted format and range, analysis domain, generation/epoch/continuity/policy, base/target, cropped axis, exact inspected bands and reference statistics. A nominal full-raster interpretation produced only by absolute magnitude must be distinguishable from positive structured picture in the proposed removed bands. Actual picture contradiction still wins.
6. **Carry it through retention.** Use its per-region reference only inside those certified excluded bands on the consumed frame. Do not overwrite the global black threshold, reuse a top reference for a different bottom band, or apply it to picture interior or a later context. A new source frame must be measured again. Preserve current final crop, optional-fill, subtitle and NLS arbitration.
7. **Use existing temporal safeguards.** Stationary strong evidence may use existing adjacent confirmation and available lookahead. Weak evidence cannot become authority merely by waiting. Moving edges retain the current motion/settlement contract. Do not introduce a multi-second blanket dwell.

A remembered bar/noise reference is not necessary for the first implementation. If later justified, it may only nominate; it must be frozen during ambiguity, scoped to source/domain, reset on context changes, and independently revalidated on current pixels. Never gradually learn picture into the black reference.

### Captured ad: independently qualified variable exterior profiles

The [native replay](native-capture-20261026.md) establishes persistent acquisition failure. All 97 payloads produce only a bottom boundary: proposed `(0,0)-(3840,1858)`, `PROVISIONAL`, with full-raster fallback. Recorded presentation remains full raster over 1,516 consecutive source frames. Confirmations are saturated, global P90 is 268-272, and lookahead has future frames but no trusted base. A timer or near-black change cannot repair this example.

The upper exterior has a broad gray gradient and fine texture; the lower exterior is nearly black. At the detector's 48 top-row sampling positions, only 21 are at or below the actual cutoff 88; 44 are required. Raising that cutoff to 104 still supplies only 31. A diagnostic bottom-mirrored 302-row upper band has P90 180 and dispersion 108, despite neutral chroma and very strong inner contrast. Existing symmetric recovery rejects it and current retention expands the top back to zero. Both nomination and excluded-pixel safety must be addressed.

This is a separate, initially shadow-only route. Do not weaken the uniform route's opposing-reference requirement or infer upper safety from the lower bar. The following is a concrete experiment design, not an already validated classifier:

1. **Find each boundary independently.** Search a bounded set of horizontal edge candidates using spatially distributed paired Y/U/V changes. Existing geometry or an opposite edge can prioritize search only. Require a localized transition and interior continuation at multiple depths in every quartile on both edges. Measure an interval of plausible edge locations and retain the outward uncertainty rows; never snap inward to a canonical aspect or to the mirrored lower coordinate. In this capture row 299 already has red chroma (median V610), so the strong 299-to-304 change does not establish a clean outside sample or authorize top=302.
2. **Represent each exterior separately.** A candidate reference is a low-frequency function `R_edge(x,y)` over only that proposed excluded band, with independently measured Y/U/V and residual noise. Start experiments with a fixed coarse horizontal profile and constant/linear depth terms, using a predetermined model-complexity ceiling. Train on separated exterior depths away from the boundary; validate on held-out depths, interleaved columns and another sampling phase. Bound gradient, curvature, chroma excursion and model extrapolation before examining positive results. Do not increase fit complexity or relax limits to make this particular image pass, fit the picture interior, or let a robust fit discard inconvenient cells as harmless outliers.
3. **Separate baseline variation from unexplained detail.** A low-frequency gray gradient may be an explainable baseline; text, contours, localized objects, chroma structure, concentrated residuals and connected detail remain independent contradictions. Inspect multiscale residuals and local maxima/components, not only global dispersion, P90 or median error. Schedule finer inspection around suspicious features and near the boundary within an explicit work budget. Incomplete coverage is unavailable evidence, never a passed safety check. Neutrality and bounded exterior complexity remain hard limits for the first experiment; arbitrary tinted/decorative panels are outside scope.
4. **Prove the local change against the local reference.** Compare inside and outside at matched columns, excluding transition/filter fringe from reference fitting. Normalize contrast by held-out residual noise plus a quantization floor, and keep separate minimum support in every quartile and at several interior depths. The current 10/18-code contrast floors are starting constraints, not sufficient qualification. Strong chroma change can corroborate localization but cannot excuse unsafe exterior content, inadequate luma support or uncertainty about the exact crop edge. Do not count correlated features as extra temporal votes.
5. **Reconcile old visibility witnesses explicitly.** Existing `HasHorizontalPictureContinuation` (`ActivePictureEvidence.cpp:695-718`) and `FindHorizontalVisibleExtent` (`:721-751`) use absolute thresholds; the raised profile itself can trigger their visible-content witnesses. Retaining those booleans unchanged can defeat the new route; clearing them wholesale would be unsafe. Preserve the raw witnesses. Only the bounded, independently validated baseline may be explained by the exact per-position profile. Residual, chroma, connected-object and unexplained witnesses still veto. Record why each raw conflict is explained or remains unresolved, and carry that typed reconciliation through final retention. No global cutoff substitution and no generic visibility-veto bypass.
6. **Remeasure the orthogonal axis within the qualified aperture.** This capture also reports horizontal `no-full-extent-support`. After independently localizing top and bottom, positively check both source sides within that exact aperture, preserve every source column and retain partial-composition/windowbox protections. Keep the original rejected axis evidence intact; the new aperture needs its own current side proof. Raised side margins or four-sided graphics cannot inherit full-width authority from the upper/lower pair.
7. **Bind proof to the exact inspected region.** Use a distinct route/certificate carrying both edge profiles, model/policy version, fit/validation coordinates, residual bounds, contradiction results, uncertainty-retaining final coordinates and all source/context identity. A flat lower band may pass the existing predicate while the upper band uses the new route, but a new combined certificate must explicitly validate both edges on the same frame and exact target. Neither edge's evidence substitutes for the other. Validate the actual final excluded bands again after any target adjustment; optional fill, NLS, history or subtitle arbitration cannot extend authority to different pixels.
8. **Keep temporal ownership separate.** Existing confirmation counts and movement/owner policies remain. A repeated paused image is useful for spatial reproducibility; it does not provide new semantic evidence that the outside band is expendable. Frame gaps invalidate a contiguous temporal proof. Complete current per-edge safety must be established before live or queued temporal acquisition; losing a certificate on a later frame requires current safe fallback through existing arbitration.

The preview also contains grain/lighting that may continue across the graphic. That ambiguity is material: a clear change in color can mark either an encoded matte or authored full-raster artwork. This design must not define every smooth neutral strip as discardable. Annotate the desired retained/excluded boundary and uncertain fringe for positive examples, keep ceiling/floor, vignette and two-band artwork negatives, and compare held-out content. If a certificate cannot separate them under the chosen picture-preservation policy, leave that route unqualified and report the limitation. One paused ad cannot establish a universally safe automatic solution. Within one observation/proof episode, never add model complexity or relax residual limits to turn rejection into acceptance. A separately calibrated model revision requires a new policy version, evidence reset and fresh held-out validation.

Minimum experiments before activation: independently raised top/bottom levels; spatial gradients of varied width and direction; fine noise versus thin text/connected objects; boundary antialiasing/ringing; neutral ceilings/floors around saturated interiors; light shafts and vignettes crossing the edge; authored two-band cards; sparse features between coarse samples; unequal bar widths; raised side margins and four-sided windows; broad low-frequency objects that a fit could absorb; two competing boundaries; moving edges; and current/next-frame certificate loss. Include the original actual capture unchanged, without inventing a top annotation from bottom symmetry. Require unchanged negative outcomes through the final submitted rectangle and the ordinary route's bounded cost/identity guarantees.

### Dark-scene and scope-to-full-raster design

The current AR-only darkness exception requires native top/bottom bars, a bar-relative interior median increase of 32, 12/16 textured tiles across all four quadrants, and tile-median spread of 16 (`ActivePictureEvidence.cpp:2194-2305`). It is deliberately stricter than the human observation that one region has visible definition. Global P90 alone must not decide whether the newly exposed strip contains picture.

Keep three separate facts: (a) remaining exterior bands are safe, (b) newly exposed regions contain distributed current picture, and (c) a precise destination rectangle is supported. Local detail can contradict the old scope crop without proving an arbitrary replacement aspect. For a dark full-raster endpoint, certify appropriate outer extents and continuous picture support rather than inventing residual bars. Sparse stars, isolated text or one-edge overlays require their existing visibility-preserving presentation handling, not automatic permanent 16:9 classification.

`AlphaSourceCropPolicy.cpp:2939,2972-2979` intentionally uses raw darkness for near-black episodes, while `LibplaceboVideoRenderer.cpp:11511-11524` blocks acquisition during episode ownership. A new target-specific handoff must identify the obsolete owner, prove the changed target independently over fresh source frames and re-run final admission. Do not replace raw darkness everywhere with the AR exception. Preserve title cards, uniform fades, startup guards and source resets.

The gradual-expansion policy intentionally holds the established scope crop while verified edges move, then settles an intermediate endpoint for about 250 ms. That previously accepted behavior is distinct from missed hard cuts and must remain in this change's regression controls.

## Frame identity and evidence accounting

- One accepted source identity contributes at most one temporal vote to a given proof. Output repeats, cache hits, worker retries and live/lookahead reuse add none.
- Texture, chroma, brightness and contrast computed from overlapping pixels are features of one observation, not independent votes.
- Both opposing edges must be supported on the same frame. Do not combine yesterday's top with today's bottom.
- Each proof route has independent contiguous evidence; a complete certificate can be chosen, but incomplete routes cannot be summed.
- Keep unavailable, pending, rejected and completed-positive results distinct. Cancellation and stale evidence cannot become black/safe.
- New authority fields participate in cache comparisons and consumer validation. Context changes invalidate them; anchored scan-step tolerance cannot accumulate drift.
- Prepared future proof applies only when the selected frame and all relevant owner/context checks match. It cannot advance acquisition on a different frame or bypass `transitionDeferred`.
