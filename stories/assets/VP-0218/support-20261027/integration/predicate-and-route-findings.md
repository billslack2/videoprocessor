## What is profile versus content evidence

The existing edge summary (`InspectHorizontalEdge`, `:337+`) fuses profile and edge evidence: blackFraction, P90, dispersion, texture, neutral fraction and continuity describe the excluded band relative to one absolute floor; inner-boundary contrast is geometry evidence. On this ad the latter is +190.8 at the nominal edge while the absolute profile assumptions fail. Texture and neutrality already pass unchanged. The retention predicate intentionally drops only contrast, because it is a safety check on previously authorized crop geometry.

`IsCrediblyVisible` / continuation / extent are the current-pixel content witnesses. They presently use the same absolute floor, so a smooth raised profile is counted as visible content. That is the precise integration seam for a typed per-edge reference: keep the original raw measurements and add a second, exact-frame residual interpretation, rather than replacing the source samples. The new interpretation may explain profile-level variation only if its local reference was independently estimated/validated; the self-fitted median17 counterfactual is diagnostic and not a certificate. Its numbers at `reference/results.json` are useful: top guard raw 6,426 visible samples / 64 occupied depths / adjacency; R=Y−median17 yields 3 samples / zero depths with ≥2 / no adjacency, while local summary values pass. This proves the absolute brightness is locally explainable, but also illustrates why a self-fitted reference can erase objects. Do not use a normalized or altered Y plane as authority.
