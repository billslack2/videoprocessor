Three independent team reviews covered cue continuity, presentation/coordinates, and adversarial regression safety. The presentation and safety reviewers rechecked mapping after the user's clarification; the design below incorporates that correction.

A. Separate three authorities
A1. Current cue proof describes source content, never AR or a right to crop.
A2. Current preparation receipt proves what this exact source packet actually erased and replaced. A prior rectangle is never permission to erase current pixels.
A3. Submitted presentation record describes what successfully reached output: selected packet identity, actual source and target rectangles, native-to-output mapping, configured fixed zoom, mode/output contract, required-content extent and representation. Recording prepared-erasure output does not make it native glyph ownership or renew the semantic ownership lease.

Keep the raw worker observation, bar evidence and AR measurements immutable. Do not substitute retained picture edges into them. New local proof travels alongside them with explicit coverage and authority flags. Do not globally relax SameContext or preparedErasureOnly restrictions.

B. Established-cue proof, independent of unrelated AR hints
Acquisition retains cue identity, exact accepted line/capture/panel geometry, owned strokes, native physical cue side and plane, source dimensions/format/range/colorspace, transport/format/analysis/renderer/viewport generations, policy and continuity epochs. Acquisition requires complete current accepted evidence and independently established cue-side placement. An unrelated missing/nearby opposite edge cannot by itself invalidate an otherwise complete cue-side acquisition. Pending, stale or prepared-erasure evidence cannot acquire a template.

For each distinct ordered admitted source packet:
- Reuse a completed exact-current worker result if it contains all required proof.
- Otherwise run a bounded established-cue inspector even when automaticSourceCrop=false/fixed zoom is active. It nominates only the acquired source-side plane, then re-proves that side from current native pixels; an independently measured conflicting current edge wins.
- Verify the acquired glyphs and backing from current pixels. If edge masking is needed, mask only freshly verified owned strokes, never a padded rectangle or old cleanup region.
- Run the existing detector over the complete relevant cue-side search area and configured companion/picture band. For a lower cue, Analyze with upper edge 0 and independently proved lower plane can inspect only that side; mirror for upper cues. This is private local inspection, not a fabricated full-picture measurement.
- Require the relevant topSearchComplete/bottomSearchComplete, no work limit, exact acquired line matching, and no additional candidates or conflicting residual content. These flags and rawEvidenceComplete are necessary but NOT sufficient: carry explicit actual coverage bounds, sampled rows and stride for every pass and require coverage of the promised configured domain. The existing detector first scans nearBarDistance=0 and widens only if no cue is found; a detected old cue can therefore leave the farther configured band unexamined. Force inspection of any missing configured band even when the narrow pass detects the old cue. Coverage describes the actual detector sampling grid, not exhaustive native pixels and never whole-raster absence/crop/UI authority. A padded old glyph ROI alone is insufficient.
- The inspector confirms existing ownership only. New, shifted or enlarged text goes through ordinary current acquisition.

Proposed proof outcomes:
NO_TEMPLATE: normal acquisition only.
CURRENT_COMPLETE: exact current cue/placement and complete relevant coverage; preserve cue identity and advance normally beyond 250 ms. Opposite/shared AR loss does not weaken this proof.
CURRENT_PARTIAL: retain the template as a candidate, but publish no stronger authority than actually verified. Any existing bounded continuation must require its current glyph/placement/capture prerequisites; missing placement cannot authorize moving text. Use a nonrenewing source-time limit capped by the existing 250 ms / configured hold. Incomplete coverage cannot reset that limit or become a positive detector result.
CONTRADICTED: current glyphs disappeared/changed, extra line/content, conflicting cue-side edge, in-picture/nav placement, changed required glyph/source-panel backing or genuine picture expansion. Invalidate affected relocation immediately; reacquire new content normally. Optional finite-cap failure invalidates only cap cleanup unless it also contradicts glyph or placement proof.
HARD_RESET: seek/discontinuity/incompatible source or policy epoch. No stale continuation.

Use actual source timestamps and the source clock for elapsed time. Repeated display outputs neither spend nor renew a lease. Source gaps require complete fresh verification or acquisition; a partial bridge spends the actual elapsed source time. One frame-wide work budget counts pending checks, local inspection and reused samples; no hidden second unlimited scan. Count direct planar detector reads as well as AnalysisLumaSource::Sample calls: P010/P210/decoded-DV must not bypass the budget. Cache exact-current proof for repeats. If coverage cannot complete, report CURRENT_PARTIAL/budget exhaustion honestly and retain the existing safe behavior; do not weaken proof to satisfy the benchmark.

Source state commits once in accepted-source order, including packets prepared ahead of temporal display. Future lookahead observations are evidence only. Output selection does not advance that source cursor. GPU preparation failure must not erase an otherwise valid source cue. Successful output submission commits presentation state separately.

C. Atomic source preparation and optional finite cap
For relocation, current glyph erasure and its matching reconstructed layer form one packet. Both must match the same source identity/context. Issue the receipt only after actual GPU preparation succeeds, including deferred native preparation. Existing subtitleCompositionSucceeded=true on geometry acceptance is not sufficient evidence of completed GPU work. Never submit repaired source without its caption, borrow the preceding frame's glyph layer or certify an unprepared frame as clean for mixing.

Finite glyph-free backing cleanup is optional and separately current-proved. Reuse an acquired outline only as candidate coordinates; recheck current body/chroma/flanks/closure/allowed extent. A failed cap proof removes only that optional cleanup, not an otherwise valid cue/layout. This separation already largely exists and must survive refactoring. Do not enlarge black thresholds, closure collars or masks as a substitute for repairing cue continuity.

Keep the accepted transparent glyph-only alpha path and isolated preparation renderer. Verify source cap pixels and untouched destination pixels together, including Clear/Yellow top/side edges and reduced glyph sizes.

D. Fixed zoom and representation invariants
Missing upper-bar/shared-hint metadata alone must not alter movie scale/translation, reset cue identity, drop its valid cleanup or change color processing. Validate the configured movie transform separately from subtitle placement. Intentional fixed-zoom side-cropping is not a residual-content conflict; required subtitle/navigation content has a separate extent.

A current prepared-erasure receipt may establish that this exact packet permits the native picture mapping. It may record successful submission. It cannot seed or renew semantic glyph ownership. Do not simply remove the fixed-crop exclusion in EvaluateQualifiedSubtitleUnknownHold: subtracting an OLD erased footprint from a CURRENT unprepared frame could hide the still-visible original caption.

If current preparation genuinely fails, do not pretend erased pixels still exist or change fixed-zoom behavior as an incidental error response. Exercise the existing mode-specific fallback and document whether it preserves required content. If an injected failure clips a required current caption, qualification is BLOCKED; preserving the old fallback does not establish safety. Resolve that failure explicitly before shipping, without assuming an automatic zoom policy is the answer. Any new recovery owner or outward/inward timing policy is a separate conditional proposal, deferred pending observed need and fixed-zoom semantics. Off's existing content-fit/hold, Classic translation and NLS policies remain unchanged in this correction.

Brightness discrimination precedes any new color-path change. With an identical native source and fixed transform, compare direct native, prepared/no-hook and prepared/subtitle outputs outside subtitle/cleanup regions, including DV/PQ/HLG and peak-history evolution across distinct and repeated frames. If an actual representation mismatch is found, evaluate a consistent preparation representation in advanced mode; do not implement it merely because dv flags differ. Preserve separate preparation/final renderers.

E. Production-shared regression seam
Extract narrow orchestration functions used by production and tests, not a parallel model:
- Source decision/admission: current worker/Resolve result -> pending/local current proof -> cue tracker -> source receipt.
- Presentation selection/commit: current prepared packet and configured transform -> crop arbitration -> temporal packet selection -> actual successful submission record.
Use real detector, Resolve, pending/tracker/continuation helpers, cap proof and composition geometry. Preserve the existing temporal ledger. A deterministic worker scheduler delays/reorders/withholds completions without sleeps. No wholesale renderer rewrite.

Tests must distinguish source analysis, preparation success, selected packet and successful submission. Failed submissions never change submitted history. Repeated output reuses immutable packet data; prepare-ahead cannot seed displayed history. Raw and reconstructed representations must not be blended across incompatible packets.

A transition ring should avoid full-frame readback every frame.
