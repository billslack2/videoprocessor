Preparation receipt versus actual submission
The source preparation record can describe deferred native work before the current packet's fields have been materialized, especially while buffering. That record is not itself a presentation receipt. The selected output must complete preflight and rendering; the renderer commits submitted-caption and presentation state only inside rendered && submitted (19061 onward). Early preparation failure returns before that boundary. This distinction prevents treating sourcePrepared as proof that the GPU has already presented a repaired frame.
