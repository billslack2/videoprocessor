Important coverage hole
SubtitleBoxLookahead::NeedsCurrentSubtitleBarStripClearance (SubtitleBoxLookahead.h:196) explicitly requires diagnosticReason != no-bright-ink. The three incident losses all have no-bright-ink. Probe confirms this reason disables clearance while an otherwise identical negative fixture is eligible. Thus the existing clearance measurement cannot be assumed present at onset. Its current consumer only handles translation undo, and SubtitlePresentationBounds ignores discardedStripClear. Reusing those boolean arguments alone cannot fix expansion.

Recommended narrow guard, requiring implementation and validation
1. Introduce a distinct current-frame historical-expansion rejection certificate for advanced subtitle modes. Bind it to exact selected analysis identity, native base, mode/policy/continuity, current native bar authority and a previously submitted native picture. Confirmed subtitle absence is only a trigger to request inspection, never safety proof by itself. Exclude real native geometry changes, explicit full-raster authority and other competing picture transitions.
2. Compute the union of ALL candidate vertical extents that would otherwise become visible: held raw envelope, retained dense FIT plus padding, and any submitted envelope that a later recovery stage could restore. Require current complete pixel coverage of every row removed by returning to native bounds. For this narrow path, leave horizontal expansion and translation contracts outside its scope. Use the strict full-row luma/chroma measurement infrastructure, not coarse AR safety. Add a separate containment predicate for expanded-to-native geometry: the current ProvesCropUndo predicate requires equal-size translated crops and is unsuitable.
3. Schedule the needed strict scan for no-bright-ink only when there is a historical expansion conflict. Bound work, preferably on the existing worker. Exact coverage is required; exhausted budget, missing row, source mismatch, discontinuity, unknown range or a conflicting pixel returns UNKNOWN/no new shrink authority. Existing thresholds are operational black-band criteria, not proof of literal zero signal. Verify faint/color UI controls against them. Never treat no-bright-ink, an aborted scan or a partial row as clear.
4. Apply the certificate before raw-envelope and dense-FIT routing so BOTH old contributors are suppressed for that source. Carry its exact frame/base identity through recovery and final selection so downstream submitted-envelope union cannot undo the decision. Do not turn this into glyph erasure, cue ownership or new native AR authority, and do not blanket-clear unclassified history. Existing unknown-frame continuation remains separately bounded; proof loss cannot renew it.
5. Independently correct owner/geometry invariants: an outward-expanded crop must undergo the relevant expansion-proof check even if labelled translation/fit confirmation. Match actual bounds, not only owner enum. Preserve exact current UI/bar evidence and already-displayed content when shrink safety is unavailable. A global owner-normalization change needs broader Classic/Off/side-expansion regression; do not infer safety from this small probe.
6. Longer-term split caption-owned and UI/picture-owned history, including dense FIT. Qualified reconstruction should retire only matching caption contributions. Raw history currently lacks provenance. Do not solve skipped-analysis expiry by simply clearing all state; require inspection or explicit bounded continuation and preserve real displayed content safely.

Why existing protections miss this
Renderer's CanRetainSubmittedScopeContinuity path is gated on !sharedGeometryAvailable, whereas incident native geometry remained available; pending translation also counts as a competing owner. Recovery's vertical-FIT gate is label-specific. Final advanced-mode placement only removes same-size translation, leaving expansion intact.

Required validation before calling a patch safe
Full production routing/recovery/selection tests: qualified cue -> complete no-bright -> qualified cue with raw+dense history; cue->unknown->cue with bounded nonrenewing lease; actual native/target geometry unchanged for fixed-ratio clear bars; faint single-pixel and chroma UI must veto shrink; partial budget/row/read failure and stale frame/policy/mode/base must not authorize shrink; true native AR/full-raster changes must remain responsive; already-submitted expansion must remain protected without a current full-clear certificate. Assert final owner and geometry agree. The present probe is synthetic state testing, not an image/video replay or patched renderer validation.
