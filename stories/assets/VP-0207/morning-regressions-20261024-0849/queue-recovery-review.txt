Narrow design for review, NOT implemented
Allow an exact queue-retirement witness to nominate the existing guard only as a PRIVATE candidate for one COMPLETE current inspection. Require exact last source/selected cue identity, unchanged format/domain/viewport/renderer/policy/settings, valid matching native source, no discontinuity, forward timestamp/source-number gap and an increased continuity epoch only. Use reusable heap scratch, retaining the original baseline but clearing cached proofs; do not move a large tracker/guard temporary back onto the host stack. Fresh native glyph, own-plane and full configured companion checks remain unchanged, using the same source budget.
Commit the new-epoch guard/proof only when that full scan succeeds and the existing selected-cue/previous-source binding accepts it; finite cap cleanup must still independently succeed. On hard current contradiction, retire the candidate. On UNKNOWN, revert the trial and preserve existing bounded pending behavior, including eventual omission. Do not claim arbitrary UNKNOWN recovery: retaining a candidate across an epoch after pending selection would require an additional explicit tracker/cursor contract.
