## Findings resolved

1. Cached raster data could survive failed transitions/read-back or external
   display changes. A coherent cache now invalidates on these boundaries and
   retirement. A generation token rejects stale observations. Current Windows
   read-back occurs at initialization and deferred renderer display processing,
   including Auto/Never; OSD polling adds no driver queries.
2. Recreated swapchains did not update the recorded drawing dimensions. Every
   successful ordinary/recreated/temporal size path now publishes geometry and
   failed/replaced buffers discard the old dimensions.
3. Long inline annotations could clip in the native 540px OSD. Raster stages
   use continuation rows, and the bitmap height uses that same row builder.
   Tests measure the actual 20px Consolas text width and execute the real native
   bitmap rasterizer to check height growth and malformed/unknown fallback.

#181's routing and two-consecutive-observation checks are now extracted into
production helpers with tests for both desktop and signal raster, GPU scaling,
known target, scan/rate mismatch, driver rounding, observation resets, full-mode
GDI routing and exact cadence-ratio ordering. DPI tests verify disabled/nested
scope restoration and physical hidden-popup client dimensions. No new test
changes Windows display mode.
