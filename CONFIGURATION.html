VideoProcessor configuration

VP-0079 uses one VideoProcessor.cfg. A section belongs to the component that owns the setting; an exact root is its baseline, or the first named section is the baseline when no root exists.

State is process-local. A key-selected child remains selected across renderer rebuilds and refresh transitions, but never survives a VP restart. There is no profile registry, disk state file, enabled: false, off_when, or clear_when.

How roots and variants work

A root section holds baseline values when present. Without a root, the first named section declared in the file is the startup baseline; later named sections inherit it and override only their listed values. A section becomes the manual in-memory selection when its when: matches a key. Each selection is rebuilt from the baseline, so switching back never retains values from the previously selected overlay. Source-only expressions are re-evaluated after a source state change or rebuild. Rules are never evaluated per frame.

[queue]
when: $key=="l"
queue_size: 32
target_frames: 3

[queue.low_latency]
when: $key=="L"
queue_size: 1
target_frames: 1

L selects the low-latency overlay; l restores the root. The same grammar applies to [vprenderer], [vprenderer.viewport], and their named children.

Application and renderer selection

[general] startup

capture_device, renderer, fullscreen choices, and startminimized are application startup settings. Command-line switches still take precedence.

Detection and cadence

scene_detect, disable_detection_features, and scene_correction_basic remain application/pipeline policy, not Alpha profile values.

HDR metadata

hdr_colorspace and hdr_luminance select the input HDR metadata policy used by the DirectShow pipeline.

[renderer_alias]

Aliases map readable names to renderer-combo indexes, for example vp: 1 and madvr: 2. They do not own renderer settings.

[shortcuts] render.<index>

Fixed renderer selection shortcuts use the one-based combo index. Profile and shader keys belong in their own when: expressions.

Queue and DirectShow

[queue] when

The root key returns queue policy to its baseline. It is normally lowercase l in the supplied configuration.

queue_size

Maximum VP queue capacity in whole frames. Set 1 only in an explicit low-latency child; it is intentionally not the default.

lead_frames

DirectShow presentation/timestamp lead in frames. It is root policy, not a madVR-private queue control.

target_frames

VP converted-frame queue target in frames.

active_picture_lookahead_frames

Diagnostic Alpha preview depth from 0 through 8 queued future frames. The current implementation logs decisions without changing rendered crop or NLS pixels. Omit it or set it to 0 for normal viewing.

Queue variant when

Each named queue child supplies its own expression and overlays only the queue values it declares.

[directshow] ingress

video_conversion chooses the input conversion path. renderer_nominal_range describes input nominal range; it is not display output range.

DirectShow timing

renderer_start_stop_time_method and frame_offset configure DirectShow timing behavior.

[directshow.conversion] conversion_method

One of AUTO, SIMD, OPTIMIZED, or STANDARD.

Conversion core limits

min_core_count and max_core_count bound the conversion worker policy.

[directshow.ppm] ppm

One source-timing correction applied at every cadence. Use an integer for a fixed correction or AUTO for the existing automatic calibration sentinel. This replaces the old per-nominal-refresh map.

VideoProcessor Renderer (Alpha)

These settings apply only to VideoProcessor Renderer (Alpha). They do not configure madVR. Use either a root [vprenderer] baseline or named-only sections. With named-only sections, the first one—for example [vprenderer.rec709]—is active at startup and later sections overlay it.

Alpha baseline when

The baseline may be [vprenderer] or the first named section. In the supplied configuration, [vprenderer.rec709] is first and F4 selects it.

Alpha variant when

A named child selects a process-local overlay such as rec709 or bt2020.

Tone and gamut

Input/tone behavior: tone_mapping, gamut_mapping, peak_detection, contrast_recovery, and sdr_input_transfer.

Scaling and cleanup

quality, up/downscalers, deband, and dithering are Alpha rendering choices.

Output and refresh

Output luminance, presentation, range, gamma, primaries, BT.2020 reporting, and switch_refresh_rate belong in the Alpha root or its variants.

[vprenderer.viewport] when

The empty viewport root is the normal 16:9 baseline.

Viewport variant when

Use a named child such as scope for a selectable layout.

Viewport layout

screen_aspect selects the target display aspect. automatic_crop lets Alpha apply trusted active-picture bounds for that viewport. Subtitle fit, hold time, and padding are Alpha-only layout controls.

Shaders

There is no blank [shader] section. An empty group root is the group’s off/baseline state. type: single is the default; omit it. Use shader_type: nls or shader_type: custom to describe the effect.

Shader group root

The root when returns that group to empty. Write type: multi only when matching children should compose; otherwise children are mutually exclusive.

Shader member

A child has a when, a shader_type, and an optional human-readable label.

Composition order

stage is pre_resize or post_resize. Use a unique numeric order within a stage to make composed stacks unambiguous.

Backend files

hlsl_file is used by madVR; glsl_file is used by Alpha. Either may be omitted, in which case that backend ignores the logical shader.

NLS values

NLS members may set geometry, strength, center protection, curve, quality, and tolerance. n selects the empty NLS root; Shift+n and Shift+p select standard and protected children in the supplied configuration.

Actions

scope

Optional; the default is vprenderer. Valid values are vprenderer, directshow, and *.

Event and condition

Current committed refresh events are refresh.applied, refresh.confirmed, and refresh.restored. Their expression variables are $actual_refresh, $requested_refresh, and $previous_refresh.

run

One command line: an .exe, .bat, or .cmd path followed by optional arguments. Actions run after a committed transition, never per frame.
