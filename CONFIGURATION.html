VideoProcessor configuration

VideoProcessor.cfg is an optional UTF-8 text file read from the application's working directory. It uses INI-style sections and key=value entries. Blank lines and lines beginning with # are ignored.

The shipped file contains common [command_line] settings only. The optional [p010_conversion] and [ppm_correction] sections can be added when needed.

Command-line arguments are applied after configuration values, allowing a shortcut or script to override a string setting. Boolean settings are enabled by setting them to true in the config or adding their command-line switch.

[command_line]

Boolean values accept true/false, yes/no, on/off, or 1/0.

LLDV

DeckLink does not expose the HDMI Dolby Vision VSIF. The newlldv option is a heuristic, not definitive detection.

With newlldv=true, VideoProcessor treats stable BT.2020 + SDR + no static HDR metadata as LLDV only when both hdr_colorspace=FOLLOW_INPUT_LLDV and hdr_luminance=FOLLOW_INPUT_LLDV are selected. After a 1.5-second confirmation it switches output to PQ and supplies synthetic metadata: MaxCLL 1000, MaxFALL 401, mastering minimum 0.001, and mastering maximum 4000.

Leave newlldv disabled for legacy behavior or whenever genuine BT.2020 SDR could be mistaken for LLDV.

[p010_conversion] (optional)

This section is used only by the V210-to-P010 formatter. When it is omitted, VideoProcessor uses smart defaults: AUTO conversion, one minimum core, and one or two maximum cores based on physical-core count.

KeyValues
ConversionMethodAUTO, SIMD, OPTIMIZED, STANDARD
MinCoreCountInteger, at least 1
MaxCoreCountInteger
[p010_conversion]
ConversionMethod=SIMD
MinCoreCount=1
MaxCoreCount=2

[ppm_correction] (optional)

This section provides per-refresh-rate timing corrections for rational timing modes. Keys are truncated refresh rates; values are PPM corrections or AUTO. If the section is absent or has no valid matching entry, VideoProcessor enables automatic PPM calibration with an initial zero correction.

[ppm_correction]
59=5
29=AUTO
23=0
  • 59 matches 59.94 Hz, 29 matches 29.97 Hz, and 23 matches 23.976 Hz.
  • Positive PPM makes the stream faster; negative PPM makes it slower.
  • AUTO enables automatic calibration for that refresh rate.

Minimal example

[command_line]
capture_device=Decklink Quad HDMI Recorder (1)
renderer=DirectShow - madVR
queue_size=32
scene_detect=false
